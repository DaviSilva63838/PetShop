# Organização das etapas

O projeto foi dividido em dez partes para acompanhar a construção do aplicativo:

1. Estrutura inicial do projeto.
2. Tela inicial e estilos.
3. Lista de serviços.
4. Formulário de cadastro do pet.
5. Salvamento do cadastro.
6. Dados e armazenamento dos agendamentos.
7. Agendamento de serviços.
8. Consulta e cancelamento de agendamentos.
9. Testes das regras de agendamento.
10. Documentação e ajustes no visual.

O histórico do repositório mostra as alterações de cada etapa.
